# 正解にする謎解き5（改修版）

公開先：`https://tankouideal.github.io/seikai5_plus/`
現行の `/seikai5/` は変更しません。

## ファイル
- `index.html`: 表紙・10問・追加ルール・クリアページを一体化したページ。画像・CSS・JavaScriptを埋め込んであります。
- `preview.png`: ゲームタイトル画像を使用したXリンクカード用画像（1200×630）。このファイルだけは公開URLで個別にアクセス可能にする必要があります。
- `sw.js`: 読み込み後のオフライン再読み込みに備えるキャッシュ機能。

## 公開方法
1. このZIPを解凍します。
2. GitHub Pages用の `tankouideal.github.io` リポジトリのルートに `seikai5_plus/` フォルダを置きます。
3. `https://tankouideal.github.io/seikai5_plus/` で表示・操作を確認します。
4. `https://tankouideal.github.io/seikai5_plus/preview.png` にアクセスできることを確認します。
5. XへのクリアポストでURLプレビューが出るか確認します。Xの取得・キャッシュ状況によっては表示されない場合があります。

## 操作
- 初回は「ゲームをはじめる」。その後はトップから「続きから遊ぶ」「最初からやり直す」を選べます。
- 「最初からやり直す」は確認後に進捗と選択を削除します。
- 未正解の問題は「設定完了」で正解しないと先へ進めません。正解済みの問題のみ「次の問題へ」ボタンが出ます。
- 第5問の後に追加ルール説明が入ります。
- ヒントは操作ボタンより下、画面全体の横方向中央に表示されます。複数ある場合は「ヒント1」「ヒント2」を直接1回のクリックで開けます。
- PC画面では左に画像、右に問題文・選択肢を配置。選択肢はマウス移動を抑えた3列のメニューです。スマホは縦並び・OS標準の選択メニューにします。
- 説明文とクリア文言は指定された文面／元のHTMLの文面を保持しています。

## 通信
- 最初の読み込みが完了した後なら、10問の画面切替え、ヒント、正誤判定はネットワークがなくても動きます。
- GitHub PagesのHTTPS環境ではService Workerによるキャッシュも試みますが、オフラインでの再読み込みが使えるのは登録と保存が成功した場合です。
- 外部リンクやX投稿には通信が必要です。
- Xカードは画像添付ではなく、URLプレビューです。表示はX側に依存します。

## デザインと操作の修正
- 背景は元の淡い黄緑系、ボタンは深緑色を採用。装飾と英語ラベルを控えめにしました。
- 「遊び方」からルールを開いても問題画面は変わりません。「トップページ」は別の明示的なリンクです。
- 「第n問」の重複見出しや不要な不正解メッセージ、クリア時の英語ラベルを削除しました。
- 元の問題文、画像、ヒント、正解判定、追加ルール、クリア文面は変更していません。

## 今回の修正
