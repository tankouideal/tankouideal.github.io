# 正解にする謎解き3（リニューアル版）

公開先: https://tankouideal.github.io/seikai3_plus/

このフォルダを GitHub Pages のリポジトリ直下にアップロードしてください。既存の `/seikai/` などのページには影響しません。

- `index.html`: 全8問と画像を1ページに内包
- `preview.png`: Xカード用（元のタイトル画像を使用）
- `sw.js`: オフライン再読み込み用キャッシュ

ブラウザのストレージを利用して、進捗を保存します。初回ロード後は通信なしでプレイでき、再読み込みはService Workerに対応する公開環境でキャッシュが作られた後に可能です。

ソースコード・画像・ヒントは元の作品から移植しています。
